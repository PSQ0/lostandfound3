# LostFound

## اعتبار سنجی چند فیلدی

## قانون پیاده سازی شده:
اگر کاربر تصویر را بارگذاری نکند حتما باید توضیحات او بیش از 20 کارکتر باشد.

## چرا؟
1. توضیحات مبهم و کوتاه و همزمان عدم بارگذاری عکس هیچ کمکی به یوزر در پیدا کردن آیتم نمیکند.
2. باعث میشود داده هایی که در سامانه ثبت میشود از ارزش اطلاعاتی بالاتری برخوردار باشند.
